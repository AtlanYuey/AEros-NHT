## 卡片大小 & iOS 26 渐进式滚动边缘 / Card size & iOS 26 scroll edge

- 新增「外观 › 卡片大小」：五档滑块（小 / 较小 / 标准 / 较大 / 大），调整网格与瀑布流每行显示的卡片数；附竖屏 / 横屏列数预览
- 列数按列表所在栏的实际宽度计算，换屏、旋转或拖动分屏分割条时自动增减；「标准」与原来的自动列数相同
- 导航栏改为 iOS 26 的柔和滚动边缘效果：内容滚到顶部栏下方时逐渐模糊并淡入页面底色，不再有生硬的半透明色块和分隔线
- 渐进模糊由着色器实现，模糊半径沿边缘连续变化，没有分层的断层
- 渐进边缘只覆盖状态栏与标题栏，栏下方的内容保持清晰
- 顶部按钮改为 Liquid Glass：语言 / 排序合并为一个玻璃胶囊（iOS 26 原生按钮组），返回、清空历史为玻璃圆形按钮；画廊详情页顶部栏同样使用渐进边缘
- 搜索框改为 iOS 26 的胶囊形状
- Added Appearance › Card Size (5 steps) for the grid and waterfall layouts, computed from the pane's actual width
- Navigation bars now use an iOS 26 style progressive scroll edge (variable blur + fade) instead of an opaque frosted bar
