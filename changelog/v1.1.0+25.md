## iOS 26 界面细节 / iOS 26 polish

- 顶部语言 / 排序玻璃胶囊在深色模式下改为深色玻璃，与底部标签栏一致（修复原生按钮组不跟随深色模式的问题）
- 顶部按钮与大标题之间留出空隙；搜索框文字与图标垂直居中
- 卡片大小可分别设置竖屏与横屏，各自带列数预览
- 所有选项选择（列表模式、阅读模式、语言、排序等）改为 iOS 26 风格的玻璃弹出菜单，从所点的按钮或行上展开，取代旧式底部操作表
- 提示框改为 iOS 26 样式：圆角玻璃卡片 + 胶囊按钮
- 阅读设置改为 iOS 26 浮动玻璃面板，右上角 ✓ 关闭
- 网页登录、网页浏览、安全验证页面改用新的顶部栏与玻璃按钮
- 开源许可页改为设置风格的列表，不再是 Material 页面
- 提示信息改为玻璃气泡；阅读器加载指示改为 iOS 风格
- Card size can be set separately for portrait and landscape
- Option pickers, alerts and sheets use iOS 26 style menus / glass cards
